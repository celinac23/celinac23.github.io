# celinac23.github.io

Personal site of Yufei (Celina) Chen — https://celinac23.github.io

## Writing a blog post

Add a file to `_posts/` named `YYYY-MM-DD-short-title.md`:

```markdown
---
title: "My post title"
description: "One line that shows up in the blog list."
tags: [research]
---

Write the post here in Markdown.
```

Push to `master` and GitHub Pages rebuilds the site in a minute or two.

## Editing other pages

- Home page: `index.html`
- CV: replace `files/celina-chen-cv.pdf`
- Name, email and links: `_config.yml`
- Colors and fonts: `assets/style.css`
